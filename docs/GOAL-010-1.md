## Part A — 実行時依存の方向

基準版を `git archive` で作った作業ツリー外の固定コピーを走査した。表示された10経路は重なりがあり、全アプリの実行時グラフでは **18 modulesのdomain SCC + 4 modulesのcontroller SCC = 2群** だった。変更後は **0群**。

| 所有する定義 | 移動前 → 移動先 | 意味 |
|---|---|---|
| EYE_HEIGHT / PLAYER_RADIUS / PLAYER_HEIGHT / FOV / camera near・far / floor・ceiling寸法 | chapter → firstPerson/constants | 数値をそのまま単一所有 |
| 旧章定義、KEY_FRAME / KEY_FRAGMENTS等 | chapter → firstPerson/legacyDefinition | 他章を読み込まず旧章の定義を初期化 |
| box / boundaryWalls | chapter → firstPerson/boundaryWalls | 純粋な境界形状生成 |
| ACTOR_COLLISION_RADIUS / ACTOR_MODEL_BOUNDS | gallery/actor → actorMotion/envelope | 行動・進行に依存しない身体境界 |
| occlusionCertificate | runtime → firstPerson/occlusion | 全8頂点・同一opaque壁の証明式を保持 |
| VAULT_AI / vaultActorEdgeOpen / vaultNoiseAudibility | vault/actor → vault/actorPolicy | worldを受け取る既存判定・全数値を保持 |
| initialProgress / emblemCheckpointForProgress / session counter | runtime → firstPerson/baseRuntime | 章選択に戻らない共通初期化 |
| RuntimeController / RuntimeSnapshot | runtimeController → controllerTypes | type-only、実行時初期化なし |
| worldForController / syncCamera / controllerCanInteract | runtimeController → controllerContext | 現在のworld、実描画準備ゲート、既存カメラ |
| soundForControllerTransition | runtimeController → controllerTransitionAudio | 受理済み遷移から同じ音イベントを分類 |

galleryは自分の純粋なworld builderを参照する。gallery/vault/theatreの直接constructorはbaseを一度だけ作り、章dispatcherへ旧章のテンプレートを求めて戻らない。公開互換exportは残し、内部は葉モジュールを参照する。セッションカウンターは全constructor共通で、明示sessionの最大値にも追従する。

依存方向は「型・数値・純粋geometry・base状態 → stage world/behavior → 章dispatcher → controller orchestration → UI」。world更新を避ける固定cache、遅延require、registry、警告抑制を導入していない。top-levelのKEY_FRAME/KEY_FRAGMENTS/staticWalls、gallery/vault固定collider、INITIAL_CHECKPOINTが循環の途中で未初期化値を受けない方向にした。

境界変更に伴う限定的な修正として、保存progressのnested object/arrayをcold constructorでコピーした。元の浅いコピーでは同じcheckpointから作る別セッションが可変状態を共有していたため、「保存復元でも独立」という受入条件を満たす。保存値・schema・正解条件の変更ではない。4章それぞれの初期runtime/world、checkpoint、復元runtime/worldのJSON値は明示sessionを固定して基準版と一致し、checkpoint/A/Bの可変参照集合も交差0だった。

## 実行可能な回帰検査

[scripts/check-runtime-cycles.cjs](../scripts/check-runtime-cycles.cjs) はインストール済みBabel/ExpoのTypeScript消去とTypeScriptのtsconfig extends/paths/baseUrl、Metro resolverを使用する。static import / re-export / barrel / require / dynamic importを列挙し、type-only・暗黙の型使用を実際に消去してから辺を作る。非literal runtime依存、解決できない内部依存、test/declarationへの実行時依存を失敗にする。依存パッケージと実在assetは境界として別記録。

iOS/native優先、Android/native優先、neutralを個別走査する。production全体・App到達・直接入口到達・到達外をそれぞれ記録し、到達外を都合よく除外しない。現在の到達外5件は型だけ4件とWelcomeScreenで、全走査には含む。

# Goal 002 実装・検証記録

## 完成した体験

ホーム → 初回のみ簡易調整3回答（スキップ可）→ 短い操作説明 → 浮遊回廊 → つながらない橋 → 結果。

調整の回答操作は最大24タップから3タップ。ホームから1面目の操作可能状態まで初回5タップ、スキップ／設定済み2タップです。実機での秒数は測っていません。

「浮遊回廊」は16ノード、下層ループ・戻れる小部屋・階段・上層回廊・上下に重なる橋。小部屋と上の見晴らし台でかけらを取り、出口へ進みます。下層を回って入口に再合流できます。

「つながらない橋」は13ノードの2島。高い島の小部屋でかけらを取り、橋端で視点をBに変えて低い島へ渡ります。低い島の庭で2つ目を取り、階段から出口へ進みます。接続している視点なら戻ることもできます。

両面に色模様と手動の「色をほどく／戻す」を実装。クリア後も同じ構図で比較できます。スコア、時間制限、補助表示の減点はありません。

## 仕掛けの区別

- 色彩立体視：同一平面の赤青模様の見かけの奥行き。人によって違い、感じなくてもクリア可能。
- 通常の立体投影：3D座標の高さ、床厚、側面、階段、遮蔽を固定カメラで2Dへ投影。
- ゲーム上の接続：離れた橋端が投影上で一致するcamera Bに限り特殊エッジが成立。色プロフィールは接続を変えない。

## 実装

Pure TypeScriptで投影・可視性・面の前後順・当たり判定・隣接グラフ・取得・勝利を管理。Skiaは投影済みの面とキャラクターを描画し、Reanimatedは一区間の移動にだけ使います。自動Zバッファ、自由視点、物理エンジンは追加していません。

全投影面の重なりを検査し、今回の固定ステージでは描画順の循環や面交差による順序反転がないことを数値で確認しました。実機の描画を実証する検査ではありません。

v1を検証して別キーのv2へ移行し、v1自体を保持。旧詳細回答・プロフィール・旧スコア、補助表示の明示選択を残します。簡易／詳細の表示元も保存します。未知版・不正データを初期値で上書きしません。

移動・完了にはsession/token、ステージ遷移にはjourneyRun。中断は最後の着地点へ戻し、古い完了通知や二重取得を拒否します。リセット中の入力と旧保存の再書き込みも防ぎます。

移動先一覧は44pt以上、VoiceOverの候補と通知は現在の状態から更新。小画面・文字拡大ではスクロール配置に切り替えます。減動時は歩行の揺れをなくし、100msの最小移動にします。

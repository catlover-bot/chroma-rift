# 第二章「測れない収蔵庫」

ホームの「測れない収蔵庫を始める」から直接入れる。前章「閉館後の展示室」の結果にも「次の章へ：測れない収蔵庫」がある。前章を未クリアでも試せるが、その記録はクリアに書き換わらない。表示調整・音・怖さ・操作の希望は共通で、調整済みなら初回 3 問を繰り返さない。

最初の 20 秒ほどで目的が分かり、初見 6〜10 分程度で探索することは設計目標であり、実測した所要時間ではない。以下は攻略を含む。見え方や怖さを感じることは正解条件ではない。

## 留め金で搬出通路を開ける

入場した補修ベイでは、上の棒が見本、下の棒が可動部品。装置へ近づき、板と取っ手が全体で見える向きで調べる。入った瞬間にカメラを移動しない。

1. 下の棒の右端の輪を横へドラッグする。左端は固定される。
2. 指を離すと現在の長さが確定する。
3. 「固定する」を別に押す。合っていれば留め金が収まり、最初の格子が開く。

「補助」で端の飾りを畳み、測定ガイドを出せる。変わるのは周囲の飾りと補助線だけで、実際の長さ・正解・カメラは変わらない。棒の両端を比較し、V 字の外側を実長に含めない。補助だけで解放しない。誤った長さは保持され、調整して再び固定できる。誤答が敵の出現や危険増加の罰になることはない。

ボタン操作・VoiceOver では「棒の長さ」を 2cm ずつ調整できる。最後は同じ「固定する」を押す。ドラッグを板の外で終えると開始時の確定値へ戻る。

## 棚の左右を使う

格子を開き、探索へ戻ると奥の隔壁越しに頭・肩の反応がある。初回提示の隔壁と作業ベイの格子は実際の遮蔽物で、姿だけを止めて安全と扱わない。

中央の大きな棚の左右が通路になっている。左側なら左の棚の端を使って視線を切り、奥の左壁の細い格子から制動ベイへ入る。右側なら中央棚の右を回り、奥で左へ渡って同じ制動ベイに入れる。敵の場所を確認し、見られている間に長い直線を進み続けず、棚の向こうへ退く。

金属床を速く踏むと、ゲーム内の音イベントが調査のきっかけになる。小さなドラッグでゆっくり歩くと弱いイベントになる。マイクは使わず、アプリを無音にしても敵のルールは変わらない。敵は最後に見た・聞いた位置を調べ、壁の向こうの現在位置を常に知るわけではない。

接近の予告が見えたら棚や曲がり角を使う。攻撃前に向きと目標が決まり、横へ避ける余地がある。捕まると最後に実際に訪れた認可済み安全地点へ戻る。解いた留め金・針とメモは保持され、再開には猶予がある。画面に触れたままなら、全ての指を一度離してから再操作する。

## 傾いた枠の中で針を鉛直にする

制動ベイは細い格子の内側にある。動かすのは一本の針で、周囲の枠は傾いたまま独立している。針の端の輪を回し、指を離してから「ロックする」。

「補助」から枠を消したり、下げ振りを出したりできる。下げ振りは重力方向の基準で、枠やカメラを回して正解を作らない。この針は両端に矢印のない棒なので、上下を逆にした向きも同じ鉛直として扱う。ボタン操作・VoiceOver では 2° ずつ調整し、同じロック操作で確定する。補助の開閉では針の角度も正解も変わらない。

ロックが外れると搬出口へ進める。旧章の紋章、明暗の二枚、輪郭円盤、配線カバー、投影鍵をこの章で繰り返すことはない。

## 搬出口で自分で扉を閉める

右奥の搬出口への短い通路では、棚と閉められる仕切りを使って視線を切る。仕切りは通過した側から取っ手を調べる。身体が通る位置に敵が重なっている場合、仕切りを瞬時に落として貫通させない。

最後の扉を通り、安全な側から入ってきた扉面と大きい取っ手へ向く。「扉を閉める」は、壁を向いたままの不可視操作には出ない。背後へ自動でカメラを振らない。

閉扉を受理するとクリアと敵停止が確定し、余韻を待たず非同期で保存を要求する。書き込みに失敗した場合は画面に通知し、未知版の原文を保護している場合は上書きしない。扉が降りる短い動きの後、向こう側の一撃と静けさが続き、約 1.4 秒の余韻後に結果へ進む。保存を音や演出の終了に依存させない。中断・背景・描画失敗は音と入力を止める。結果は閉扉の指の離しを引き継がず、新しい押下またはアクセシビリティの明示アクションを受ける。

## 任意の壁と発見メモ

短い壁面のタイルは任意のカフェウォール型比較。調べて明暗をそろえ、同じ直線の目地を比べられる。壁、床、目地の位置は変わらず、第三の必須問題にはしない。

一時停止の「発見メモ」には調べた項目だけを出す。長さ・針・タイルの各説明と、実際に動かせる比較図がある。メモの補助は現在の状態を表示し、比較しても本編の確定値や解放を変更しない。結果のメモでは敵なしで三項目を自由比較できる。未体験の項目を発見済みに保存せず、主観的な錯視の発生や健康診断の記録にも使わない。

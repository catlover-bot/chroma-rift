## 説明文

見えているものを、信じすぎないでください。

閉館後の知覚展示館。ひとりで点検をしていたはずなのに、館内にはもう一つの気配が残っています。

『錯視館』は、錯覚を使った仕掛けを確かめながら館内を進む、一人称のホラー脱出ゲームです。

色と輪郭、長さと傾き、光と影、鏡に映る背後。見る位置や周囲の手掛かりを変えながら、閉ざされた道を開いていきます。巡回する展示体の動きを観察し、棚や設備を利用して退館を目指してください。

第一章「最後の退館者」は、全5エリアで完結します。ドラッグでの移動と見回し、操作の補助、音と怖さの調整に対応しています。

錯覚の感じ方には個人差があります。見え方を検査・診断するアプリではありません。遊んでいて不快に感じた場合は、休憩するか表示・音の設定を調整してください。

## プロモーション文

閉館後の知覚展示館で、錯覚の仕掛けと巡回体に向き合う。第一章「最後の退館者」、全5エリアの一人称ホラー脱出ゲーム。

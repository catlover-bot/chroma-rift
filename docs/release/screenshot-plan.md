# 提出スクリーンショットの撮影計画

**FINAL_SCREENSHOTS=PENDING**。2026-09-19時点で、このGoalの提出候補productionを実機／Simulatorから撮った最終素材は未作成。既存のThree＋ブラウザーHUD検証画像はiPhone撮影素材として提出しない。

[Apple Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)を2026-09-19に確認。縦向き、JPEGまたはPNG、アルファなし。第一候補は**iPhone 16 Pro Maxの1320×2868 px、iPhone 6.9枠、5枚**。実際に利用できる同機種の実機／Simulatorを記録して撮影する。6.9枠には1290×2796（例：iPhone 15 Pro Max）や1260×2736も掲載されているが、実際の撮影元と一致する寸法を選ぶ。

6.9枠を提供できない場合の6.5枠は1284×2778（例：iPhone 13 Pro Max）または1242×2688。6.9枠と6.5枠の両方が一律必須という意味ではない。今回iPad対応やMac／Vision Pro配布を追加しない。

| 枚 | 実際に撮る場面 | 手順と説明案 |
| --- | --- | --- |
| 1 | 01・非常灯が点いた展示室の探索 | 新規テスト進行で非常灯を操作し、展示と通路が読める位置で撮影。「錯視館／閉館後の知覚展示館へ」。名前を添える場合は現在名の説明キャプションとして実画面の外に置く。古い画面を書き換えない。 |
| 2 | 02・長さ、または傾きの装置 | 装置を調べ、調整した棒と見本・結果が一緒に見える瞬間を撮る。「見る手掛かりを変え、仕掛けを確かめる」。答えを全て列挙しない。 |
| 3 | 03・巡回体を観察して退避 | 棚・設備による遮蔽と巡回体の位置が読める安全な場面。「巡回を読み、進む時を選ぶ」。ゲームにない追跡演出を合成しない。 |
| 4 | 04・鏡と巻き上げレバー | 正面から操作できる位置で、実際の鏡像とレバー／格子の関係が読める瞬間。「鏡で背後を確かめ、格子を巻き上げる」。別の敵や偽の鏡像を貼り足さない。 |
| 5 | 05・退館制御室の入口または安全側設備 | 最終停止・エンディングの文面を映さず、最後の区画を紹介。「第一章『最後の退館者』全5エリア」。全5エリアが同時に映る架空画面を作らない。 |

まず各5枚の無加工原本を保存する。任意のキャプション付き派生版は、原本・使用範囲・文言・書き出し手順を別に残し、画面のUIや状態は改変しない。最終画像に診断、生のID、開発ラボ、接続先、個人情報、別ブランドがないことを目視する。[正確なメタデータの要件](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata)も提出時に再確認する。

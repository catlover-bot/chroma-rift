# 「帰り道のない入口」— 攻略と状態（Goal 005）

通常は左ドラッグで歩き、右ドラッグで見回す。どちらも指を離すと止まる。一時停止からボタン操作も選べる。第一室60〜120秒、全章5〜8分は設計目標で、初見プレイによる測定はまだない。

## 第一の謎「触れない紋章」

前室から入口を通り、第一室の奥の扉の右壁へ進む。目の高さの板に二つの輪郭、その下に丸・ひし形・四角の印がある。

1. 板の見える範囲へ照準を合わせ、近くで「紋章を調べる」。「触れた指は、壁で止まる。」と反応する。
2. 「切れずにつながる輪郭を探す」。色の前後を判断する必要はない。「色をほどく」で比べたり、横へ歩いて観察したりできる。
3. 途切れていない輪郭と同じ形の、物理的な印を押す。初期seed21では内側の丸が連続し、外側のひし形に切れ目がある。
4. 正しい印が少し沈み、隣のかんぬきが戻り、既存の北の扉が上がる。間違うと印が戻るだけで、観察・種・ヒント・設定は失わない。
5. 実際に開いた通路から北へ進む。

旧しるべ・床の輪・床装置は第一室から撤去した。旧guideExamined/markActivatedはセーブ互換用の値だけで、観察・解錠には使わない。紋章を解いた後に追加で旧課題をする必要はない。

比較は紋章を見られる距離と遮蔽を再確認して受け付け、1秒未満の連続切替を拒否する。この間隔は操作上の抑制で、医学的な安全保証ではない。色・補助・プロフィールは種や答えを変えない。

## ヒントと読み上げ

一時停止のヒントを自分で開く。第1段階は線の行き先、第2段階は片方の切れ目と無彩色比較、第3段階は連続する形と印を対応させる。時間経過による自動開示はない。

「輪郭ガイド」は連続する線を静かな中立色で示す。カメラも形も動かさず、減点も自動解錠もない。使用中と表示する。

VoiceOverでは移動・旋回・文脈操作に加え、「近くの紋章と印」のカスタムアクションから見えていて届く物理対象を選べる。調べた後は線の連続／切れ目を読み上げる。離れた対象、壁の向こう、停止中の操作は拒否する。この経路で鍵は選べない。

## 鍵・帰路・出口（維持）

北の通路を抜け、折れ曲がる回廊を右へ進む。鍵の部屋の西の小部屋は戻れる寄り道。床の観察の輪（8,1.6,-13.5）から奥の額縁を正面に見て、異なる距離の三片が重なった時だけ「鍵を重ねる」を押す。実カメラの投影行列・位置・誤差・画面内・遮蔽を検査し、通常対象の6°取得はこの判定を緩めない。

難しければ鍵のヒントを3段階まで開き、自分で観察の輪へ歩いて「近くで視点を合わせる」。位置や解錠確定は代行しない。

第二の封印で南東の扉から短い帰路が開く。南へ歩き左へ折れると第一室に再合流する。来た回廊も戻れる。入口の同じ額縁・柱の先が広い出口の間へ変わる。プレイヤーが変更領域の外にいて、その直方体全体が固定壁に遮蔽され、差し替え前後で安全な時だけ一度切り替える。瞬間移動・強制旋回はない。

最後の扉へ近づいて調べ、開いた扉を自分で通り抜けると脱出する。

## 状態と保存

| 状態 | 条件 | 結果 |
| --- | --- | --- |
| emblem.phase=observing | 可視の板へ接近して調べる | 観察を一度保存 |
| sealA + emblem.phase=released | 観察後に正しい印を操作 | 同じ状態更新で北の扉を解放 |
| sealB | 正確な鍵の投影合わせと操作 | 帰路の扉を解放 |
| variant=exit | 両封印＋変更範囲外＋遮蔽証明 | 入口の先を一度変更 |
| exitDoorOpen / cleared | 最後の扉を操作／通過 | 出口を開く／脱出 |

既存chapter.v1のprogressへ任意のversion付きemblemを追加する。新しい実行はseed21で固定。再入場・比較・誤答・ヒント・設定では変更しない。旧sealA=trueは紋章を解放済みとして扱い、sealB・帰路・出口は保つ。

旧データの最初の移行保存の前に原文をpre-emblem.v1へ一度バックアップする。未知のemblem版は原文を保持して章の自動保存を止める。不正任意項目は安全な状態へ戻し、元の章記録をバックアップしてから保存する。「章を最初から」は章とその移行バックアップだけを消し、設定・調整・旧迷宮スコアは保持する。

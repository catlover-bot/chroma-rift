# 「帰り道のない入口」— 完全な攻略と状態

初見5〜8分は設計目標で未計測。中立色の平坦室・回廊・開閉扉からなる手作りの1章。通常は左のドラッグで歩き、右のドラッグで見回す。一時停止からボタン操作も選べる。

## 構成

小さな前室→額縁と柱のある入口→色模様の床→北の扉→折れ曲がる回廊→鍵の部屋。

鍵の部屋の西に戻れる小部屋がある。第二の封印後、南東の扉から短い帰路が開き床の部屋へ再合流する。元の回廊も逆走できる。入口の同じ額縁・柱の先が広い出口の間へ変わる。

## 攻略

1. 「遊ぶ」から3問へ各1回回答するかスキップし、「迷宮へ入る」。
2. 前室から進み、床の部屋の入口の「光のしるべ」へ近づく。少し下を向いて中央の照準へ寄せ、「しるべを調べる」。近くの見えるしるべは中心6°以内でも取得でき、細かな一点合わせを要求しない。中立色の標識が床に沿って中央の輪へ進む。減動時は最終位置を示す。
3. 「足跡は、途切れていない」を手掛かりに色模様の上を歩く。床は平ら。中央の中立色の輪に入ると印が有効になる。
4. 奥の扉の右にある装置を近くで調べる。しるべ＋輪が揃うと第一の封印が解け、北の扉が開く。先に輪や装置へ行っても失敗・死亡にはならず、後から必要な操作を満たせる。
5. 北の扉から進み、回廊を右へ曲がり鍵の部屋へ入る。片は異なる距離にあり、入口からはばらばらに見える。西の小部屋へ寄り道して戻れる。
6. 部屋の床の輪に立ち、奥の額縁を正面に見る。観察点は(8,1.6,-13.5)、yaw/pitchは0。形が重なったときだけ「重ねる」を使える。押すと第二の封印が解け南東の帰路が開く。視線を外しても成功は戻らない。
7. 難しい場合、一時停止からヒントを3段階まで開く。輪まで自分で歩き、近くで「視点を合わせる」を操作する。位置や解答確定を代行する補助ではない。
8. 覚えのある入口へ戻る。南東の扉から南へ歩き、左へ折れると床の部屋へ再合流する。来た回廊を逆走してもよい。
9. 入口を通り最初の小さな扉の先を見る。同じ柱・額縁を残して広い出口の間に変わっている。強制旋回や瞬間移動はない。
10. 奥の「最後の扉」を近くで調べ、開いた扉の向こうへ自分で歩くと脱出。結果は章と発見した3つの仕掛け。

## フラグとヒント

| フラグ | 条件 | 結果 |
| --- | --- | --- |
| guideExamined | しるべを接近・照準・調べる | 床面案内 |
| markActivated | 中央の輪へ入る | 印の有効化 |
| sealA | しるべ＋輪の後に装置操作 | 北の扉を開く |
| sealB | 実行列で鍵が整列し「重ねる」 | 帰路の扉を開く |
| variant=exit | 両封印＋範囲外＋全変更領域が遮蔽 | 前室を出口の間へ一度だけ差し替え |
| exitDoorOpen | 最後の扉へ接近・照準・操作 | 扉を開く |
| cleared | 開いた最後の扉を通り抜ける | 脱出 |

ヒントは注目箇所→観察方法→具体的操作の3段階。進行に合わせて文を変え、待ち時間・減点はない。遠隔で装置を操作できない。

## 投影と部屋差し替え

鍵は正解姿勢と額縁面の輪郭を先に定義し、3部分を異なる奥行きへ同じ視線上に置く。実カメラview/projection matrixで投影し、額縁に対する正規化誤差・立ち位置・前後・画面内・遮蔽を検査。床に立つだけでは成立しない。縦画面aspectが異なっても同じ輪郭を基準にする。凝視時間は不要。

前室の差し替えは、プレイヤーが範囲外の支持床上にいて、変更する直方体の全頂点への線分が同じ固定不透明壁の内側を通る時だけ。凸な領域と矩形壁に限った証明で、画面外の一点やyawだけを見ない。前後のworldで安全位置を確認し、variantの1回の状態変更から描画と衝突を更新する。

## 保存と意味

schemaVersion、chapterId、levelVersion、進行フラグ、安全チェックポイントを専用文書に保存。不正位置は安全地点へ戻す。封印・variant・出口扉を保持。「章を最初から」は旧設定・詳細調整・スコアを消さない。導入完了と操作案内確認は別のlocal文書に保存し、章を再開しても保持する。欠けた新しい任意項目は既定値を使い、旧保存を全消去しない。

色模様の奥行きは個人差があり正解条件ではない。床や壁の遠近は通常の3D、鍵は図形の投影合わせ、帰路は手作りの空間差し替え。純粋な色彩立体視を測定したとは扱わない。

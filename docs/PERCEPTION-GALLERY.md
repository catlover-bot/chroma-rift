# 閉館後の展示室 — Goal 008

同じ logical chapter ID `perception-gallery-v1` を改訂し、levelVersion / gallery schema を 3 にした。第三の章を増やさず、旧「帰り道のない入口」は独立して残す。Goal 007 の B/C・電源取得・設定を引き継ぎ、A/D の旧課題は戻さない。

## 攻略と観察

非常灯を点け、出口盤を調べ、B と C を任意の順に解く。それぞれ別操作で電源を取り、二個を出口盤へ接続する。**新たな必須課題は配線ひとつ**。線の高さを合わせて「接続する」を押すと通路が開く。カバーを退ける比較は任意で、比較したことを解放条件にしない。通路で展示体を避け、最後の安全な敷居へ歩き、**「扉を閉める」**を明示操作して終わる。

色の番号、凹面仮面、ハイブリッド掲示、音の錯覚は任意の観察。見え方・聞こえ方を正誤や進行条件にしない。凹面仮面は固定した geometry / transform のままで、プレイヤーへの追従回転をしない。横の窓は何度でも開閉できる。移動展示体の顔は別 geometry / ID / transform であり、この静止仮面を置換しない。

ハイブリッドは一枚の合成画像。歩くことによる投影サイズと mipmap で読み取りやすい成分が変わる。近 / 遠で別画像を差し替えない。実際の見え方には端末や観察条件の差があり、今回の自動検査は個人の知覚を測定していない。

## 配線の操作

右端の取っ手は線の高さ、カバー下側の取っ手は遮蔽物の横位置を動かす。描画と指操作は同じ板の local 座標を使う。片方の指だけが取得し、途中値は transient に保持、内側で指を離して確定する。cancel、外 drop、一時停止、古い callback は未確定の値を保存・接続しない。

左の中心線は `y = tan(40°) x − .1`、右は `+ offset`。高さの範囲は ±.28m、正解許容は ±.028m。カバーは x∈[−.97, 0] を動き、線の高さ・傾き・正解を変えない。指の解放後、独立した「接続する」で判定する。不一致でも位置を修正して再試行でき、即死やリセットにしない。

簡単操作 / VoiceOver では「線の高さ」「カバーの位置」の adjustable と上下 / 左右ボタンを用意する。正解の自動配置は行わない。48pt 以上のボタン、操作中の ScrollView、戻ると pause を保ち、文字拡大だけで標準 drag 希望を切り替えない。B/C の操作中と同様、中央照準は隠して比較図を覆わない。

## 発見メモ

静的カタログは七項目で、登録自体は発見ではない。

| 項目 | 比較 |
| --- | --- |
| 色の奥行き | 同じ番号・形でカラー / 無彩色 |
| 明暗の対比 | 同じ RGB の見本を元 / 共通背景で比較 |
| 主観的輪郭 | 円盤の向きを変える。補助の輪郭ガイドは別操作 |
| 凹面の仮面 | 同じ凹面を比較用視点で正面 / 側面から見る |
| 隠れた配線 | 高さを変える操作と、固定した高さで cover だけを退ける比較 |
| 近づくと変わる掲示 | 同じ合成画像の連続した拡大縮小。LP / HP 単体は明示した補助 |
| 音の錯覚 | 任意の短い再生、停止、効果音量、演出音 off |

本編で実際に観察・比較・体験した項目だけが途中の一覧に出る。各メモは体験後の一文、2〜3 文の説明、操作できる比較、出典と素材クレジットを持つ。未発見の説明を先に並べない。クリア後の結果からは七項目を「自由比較」として開けるが、本編の discovery bit を追加しない。旧クリア記録からも自由比較に入れる。

開く前に指の解放 barrier を設け、本編を pause する。閉じた後も一時停止に戻り、明示した再開と新しい指入力が必要。メモだけの状態・slider・preview は checkpoint にしない。背景移行 / 描画失敗 / 退出で比較音と preview を止め、古い callback は次の表示を動かさない。

2D の比較は既存 Skia で生成し、画像を切り替える際と閉じる際に資源を解放する。仮面は既存 Three Canvas / renderer / resources を維持し、独立した比較用 camera を使う。本編 camera・pose・行列・actor は変更しない。比較中にメイン世界の巡回や ambient / 足音を進めない。Native renderer を新たに作る手順はない。

## 音と怖さ

標準 / 控えめ、音の全体 on/off、環境音量、効果音量、演出音 on/off は独立した設定。Shepard の再生は音 enabled・効果音量 > 0・演出音 enabled・標準のすべてが必要で、メモでも同じ条件。控えめに変えた時、stop、メモを閉じる時、pause / background / failure / dispose は pending seek を含めて停止する。12 秒の自作 WAV は有限の一回再生で、大きくなり続ける音量を使わない。

展示体の巡回・予兆・初回電源後の横切りは本編の時間だけで進む。控えめでは姿と気配を残し、追尾・接触による戻しを止める。発見メモ中とクリア後は危険を進めない。閉扉は finalDoorClosed / cleared / actor resolved を同じ意味更新で確定し、保存後も退行しない。画面は約 .6 秒の閉扉表示が終わるまで結果へ遷移せず、復元されたクリア記録に演出を再実行しない。

## 保存の互換性

新しい保存 key は `chroma-rift.perception-gallery.v3`、直前版は `.v2`。まず v3 を読み、不在の場合だけ v2、さらに不在なら v1 を strict に解析する。壊れた / 未知の現在版を古い記録で上書きしない。v2 原文を `.pre-v3` へ backup してから新 v3 を保存し、元 key は変更しない。v1 からの直接移行でも既存 `.pre-v2` backup を保つ。保存 queue・session lease・reset epoch・未知版保護を維持する。

v2 の B/C・電源・接続・旧クリアを保存する。既に接続した / 終盤 / クリアした記録は、配線の `solved + compatibleBypass` を立てて進行を戻さない。追加した七発見と初回横切りの二 bit は false で移行し、旧進行から新版体験を捏造しない。クリアは `finalDoorClosed` を保ち安全な checkpoint へ移す。B/C seed と配置は継続時に作り直さない。

章だけ再開始すると新 seed の v3 で始める。元 v1 / v2 raw と backup、旧章、音や怖さ等の共有設定は残す。「保存データをリセット」は全データ削除を意図した別操作で、新版確認に必須ではない。

## Goal 007 当時の設計（履歴）

Goal 007 は展示室の改訂版。logical chapter ID は `perception-gallery-v1` のまま、`levelVersion=2`、gallery の保存 schema は 2 とする。ホームに第三の似た章を追加しない。旧「帰り道のない入口」（`returnless-entrance`）の保存と再プレイは独立して保持する。

新版は「出口を探す」から始まる。旧紋章 A、投影の鍵 D、入口を広い部屋へ差し替える結末は、新版の課題・扉条件・結果に使わない。旧章の対応部品と攻略条件は残す。

## 初めの操作と攻略

1. 開始視点で閉じたサービス通路と大きな非常灯スイッチを見る。「非常灯を点ける」でレバーと床の導線灯が反応する。不正解・暗号・色の判定はない。
2. 出口の電源盤を調べると「予備電源が二つ必要だ」。目的は「予備電源を探す 0/2」になる。スイッチや盤を先に触らず部屋へ行っても、後で戻って進める。
3. 左の B「影の見本」と右の C「描かれていない形」を好きな順に解く。それぞれの引き出しを開けた後、**「電源を取る」**を一度押す。解くことと取得は別の明示操作である。
4. 二個を持って出口盤へ戻り、「電源を接続」を押す。所持数を再検査し、二個を一つの進行更新で接続する。サービス通路が開く。
5. 棚や柱の陰を使って短い巡回通路を進み、最後の非常扉を自分で開け、その外へ歩いて脱出する。

初回の表示調整は従来の 3 問で、スキップできる。詳しい調整は任意。入場前にはスイッチの案内と短い怖さ説明を表示し、追加の長い設定質問は行わない。理解までの 10〜20 秒はプレイテストの目安で、時間制限や実測値ではない。

## B：何をどこへ動かすか

目的は **「同じ灰色の2枚を、下の四角い枠へ置く」**。見本と四角いトレーの形を対応させ、外側のつまみをつかんで運べる。つまみ・番号・選択の強調は灰色の中心を覆わない。

| 状態 | 消えない操作案内 | 比べる |
| --- | --- | --- |
| 0 枚 | 見本を1枚、下の枠へドラッグ | 無効 |
| 1 枚 | もう1枚を、隣の枠へ | 無効 |
| 別 ID の 2 枚 | 同じ灰色か確かめて「比べる」 | 指を離した後に有効 |
| 不一致 | 明るさが違う。どちらかを入れ替えよう。 | 入れ替えて再試行 |
| 一致 | 引き出しが開いた。電源を取ろう。 | 「電源を取る」に進む |

見本は同じ opaque sRGB gray `#808080` の二枚と、`#B0B0B0` または `#505050` の一枚。不一致の ID と値を組み合わせた 6 種の variant を持つ。source、ドラッグ中、トレー上、背景比較のどこでも同じ見本の RGB は変わらない。

「背景をそろえる」は元の文脈と中立背景の任意比較。「動かし方」は手順図だけを出し、正解の見本を代わりに動かさない。比較履歴は成功条件ではなく、正しい二枚を自力で選べばそのまま「比べる」が使える。配置だけでは引き出しは開かない。

持ち始めの offset を保ち、枠上では形と明度で置き先を示す。置いた見本の持ち直し・入れ替え・元位置への返却ができる。無効な drop や cancel は最後の確定位置へ戻し、同じ ID を二枚分として扱わない。

## C：回し方と揃った状態を分ける

目的は **「3枚を回して、切れ目を中央へ向ける」**。最初から「黒い円盤のふちをドラッグして回す」と伝え、円盤外側の取っ手・回転の手掛かりで操作を示す。

「中心を向いた円盤 0/3〜3/3」は実際の表示角から数える。正規の目標角は各頂点から重心への `atan2`、許容角は 8°。3/3 で指を離した後に「引き出しを開く」が有効になる。途中では「あと1枚の向きを合わせる」など理由を表示する。

円盤の中心 25% は角度追跡を中断し、外へ戻る最初のイベントで基準を置き直す。指を離す時だけ角度を確定し、pause/cancel では最後の確定角へ戻る。表示・保存・正誤は同じ角度を使う。整列数は機械的な角度の状態であり、人が主観的輪郭を感じた測定ではない。

通常の中央に三角形の線・面を描かない。任意の「輪郭ガイド」だけが破線と使用中表示を重ねる。ガイド単独では開かず、角度と明示操作で判定する。開いた引き出しの電源は別の「電源を取る」で取得する。

## 操作面と表示の境界

左ドラッグは歩行、右ドラッグは見回し。左手設定では役割を逆にする。装置を明示選択すると歩行・見回しを止め、同じ位置・camera・renderer のまま操作する。近さ、板全体の投影範囲、遮蔽、HUD の余白を確認する。届かない状態や板が切れる位置は理由を表示し、壁越し操作や強制 camera 移動では解決しない。

装置中の目的と短い案内は装置パネルに集め、通常の目的・toast を重ねない。gallery の Canvas は文字拡大や簡単操作でも全高を保持する。板の実投影下端より下にスクロールできる操作欄を置き、48pt のボタン、説明、背景比較、取得、戻るへ到達できる構成にする。実 Native の文字測定・指操作・他アプリの開発 overlay との重なりは実機確認として分ける。

VoiceOver と明示したボタン操作は同じ domain へつながる。B は意味付き見本選択と配置、C は 5° 単位の adjustable 操作を使う。文字拡大や Reduce Motion だけではドラッグ希望を変えない。古い touch・アクセシビリティ callback は操作モード変更、pause、再試行、退出後に再利用しない。

B の背景比較と C のガイドには共通 1,000ms の手動操作間隔を置く。連打抑制であり医学的な安全性保証ではない。序盤の平面展示番号は任意に「色をほどく」で比較できる。赤と青を別の深度へ分けず、比較で地形・camera・actor・正解条件を変えない。

## 気配、巡回、控えめ

非常灯の後、格子越しの遠景に非対称の展示体を見せる。最初の電源を取った後は、見通し分離が確認できる時だけ管理通路側へ移り、空の台と一度の足音・字幕で不在を伝える。画面内で突然消すための単一点判定は使わない。

二電源の接続後は短いサービス通路が回避場面になる。棚の退避地点を使い、「姿を見る→陰へ退く→通過を待つ→出口へ進む」を移動操作だけで行う。B/C の装置部屋へ展示体は侵入しない。接触復旧は通路手前の安全地点へ戻すが、B/C の解決、取得、接続を失わない。

怖さは `horrorIntensity` として独立保存する。

| 設定 | 体験 |
| --- | --- |
| 標準 | 予兆、不在、巡回、接近、接触時の安全復旧 |
| 控えめ | 予兆・遠景・環境変化を残し、追尾と接触によるやり直しを無効化 |

謎と出口条件は同じで、減点はない。怖さ変更で音量、色、Reduce Motion、文字、VoiceOver、保存した操作希望を変更しない。pause・背景・GL failure・装置操作・読み込み中は actor の進行と該当音を止める。復帰直後に不意の接触を再開しない。全画面の顔、絶叫、点滅、突然の camera 操作を怖さの手段にしない。

## Gate と保存

| Gate / 更新 | 必要な条件 |
| --- | --- |
| 入口→B/C | 歩行可能。旧 A 不要 |
| B の引き出し | 別 ID の同じ灰色二枚＋明示「比べる」 |
| C の引き出し | 3/3 の確定角＋明示「引き出しを開く」 |
| 各電源取得 | 対応する引き出しが開き、未取得＋明示「電源を取る」 |
| サービス通路 | 二個を取得し、出口盤で同時に接続 |
| 最終非常扉 | 接続済み、安全な最終領域から明示操作 |
| 完了 | 開いた非常扉の外へ歩く |

章全体の一つの checkpoint が B/C・電源・扉・物語イベントを保存し、別 writer で同じ進行を二重管理しない。新規開始と明示章 reset でだけ 32-bit seed を選び、B/C 共通 seed、B `seed % 6` variant を保存する。再開や描画再試行では引き直さない。

| 記録 | キー / 処理 |
| --- | --- |
| 旧章 | `chroma-rift.first-person.chapter.v1` を継続 |
| 新版展示室 | `chroma-rift.perception-gallery.v2` |
| 旧展示室原文 | `chroma-rift.perception-gallery.v1` を非破壊で保持 |
| v1 移行前の原文バックアップ | `chroma-rift.perception-gallery.pre-v2` に一度だけ保存 |
| v2 位置復旧前の原文 | `chroma-rift.perception-gallery.backup.v2` |

v2 が存在しない時だけ v1 を厳密に読む。v2 の未知版・破損を v1 へ降格して上書きしない。移行または位置復旧は原文 backup の成功後に v2 を保存する。開始画面から native scene へ入る前にその保存を試み、失敗時は原文を保持して同じ起動中の進行を続ける。

| v1 の状態 | v2 への引き継ぎ |
| --- | --- |
| 未開始 | 新版の導入から。旧 A は出さない |
| A / 入口の確認済み | 非常灯・入口説明を済みとして扱える |
| B 解決済み | B 解決済み＋B 電源取得済み |
| C 解決済み | C 解決済み＋C 電源取得済み |
| D / 帰路済み | 取得済みの二電源を接続済みにする |
| cleared | クリアを保持。結果は「以前の展示室のクリア記録」と表示し、新版を経験したとは述べない |
| 古い位置 / 壁内 / 危険な位置 | 進行を保った新版の認可済み安全 checkpoint へ |
| 未知版 / 不正 JSON | 原 raw を保持し、その章の保存を停止。明示 reset まで安全な試行として扱う |

物語の処理済み状態と巡回の瞬間状態は分ける。`story.foreshadowed / absence / serviceWarned / resolved` は保存し、true を false へ戻さない。実時刻、追尾タイマー、active touches、装置モード、再生音、Promise、renderer は保存しない。v1 途中記録から一回イベントを大量に再生しない。

直列 queue、reset 世代、session lease を維持する。新版だけの reset は新しい seed の v2 checkpoint を一回の書込みで置き換える。v2 を削除して残った v1 を再移行する方式にしない。v1 と移行 backup、旧章、共有設定・調整は残す。両版の原文を含めた削除は、ユーザーが明示する全データ reset のみ。

データや画像の正しさ、人の理解、実指操作、怖さ、錯視、実聴、端末性能は別々に記録する。色彩立体視、B の明暗対比、C の主観的輪郭、本物の 3D 展示体、スクリプトの不在を同じ科学現象と呼ばない。[Goal 007](GOAL-007.md)、[画像 QA](qa-goal007/README.md)、[実機手順](IPHONE_VALIDATION.md)を参照。

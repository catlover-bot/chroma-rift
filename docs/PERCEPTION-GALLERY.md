# 不確かな展示室

Goal 006 の新章は `perception-gallery-v1`。旧「帰り道のない入口」（`returnless-entrance`）とは進行と保存を分けている。ホームの主動線は「新しい展示室を始める」、記録がある場合は「展示室の続きから」。旧章には別の「旧章の続きから」があり、新しい B/C を旧章の出口条件に足していない。

初回の表示調整は従来どおり 3 問で、スキップできる。詳しい調整は設定から任意で行う。設定・表示パレット・操作の希望・音量は両章で共有する。

## 通常の導線

入口の双柱と欠けた枠を覚えながら、自分で A の板へ近づく。板の全体と三つの印が見える床の目印が観察場所になる。A の扉を通ると中央回廊へ出る。左の格子棚が B、右の大きな円盤が C。B/C はどちらから解いてもよい。両方の封印を外すと奥の D へ進める。

D の鍵を重ねると短い帰路が開く。入口の目印をたどって戻り、同じ枠の先に広がった空間へ進む。最後の扉を自分で開き、その先まで歩くと完了になる。所要 8〜12 分は設計目標で、待ち時間の条件や実測結果ではない。

左ドラッグは歩行、右ドラッグは見回し。左手設定では役割が逆になる。B/C で「動かす」を選ぶと、その位置とカメラを保ったまま装置操作に入る。装置操作中は歩行・見回しへ入力を流さず、「探索へ戻る」で歩行に戻り、一時停止では操作を止められる。再開時に残った指を新しいドラッグとして再利用しない。

## 正式な攻略と補助

| 展示 | 操作と成功条件 | 誤操作・比較・補助 | 空間の反応 |
| --- | --- | --- | --- |
| A 触れない紋章 | 板を調べ、切れずにつながる輪郭と同じ形の実体スイッチを押す。初期 seed は 21。 | 色比較は任意。輪郭ガイドも任意。色の前後をどう感じるかは正誤に使わない。誤った印は短く戻り、進行は失わない。 | 選んだ印が沈み、かんぬきが外れ、中央回廊への扉が開く。 |
| B 影の見本 | 三枚の見本から、同じ灰色の別々の二枚を左右のソケットへ動かし、「つなぐ」を明示的に選ぶ。 | 比較台へ運んでも見本の RGB は変わらない。周囲を中立にする比較は任意。外への drop/cancel は最後の確定位置へ戻る。見本は自分の元位置へ戻せる。重複・不正 ID は拒否する。 | 見本の装置の封印と翼の近道が開く。 |
| C 描かれていない形 | 三枚の欠けた円盤を回し、それぞれの切り欠きを三角形の内側へ向けて「封印に触れる」。 | 各円盤の目標方向はその頂点から重心への方向。通常表示の中央には三角形の線・塗りを描かない。「輪郭ガイド」だけが補助の破線を別に表示する。誤答でも円盤や進行を失わない。 | 小さな引き出しと翼の封印が反応する。 |
| D 重なる鍵 | 観察位置へ歩き、実際に投影される鍵の断片を完成形へ重ね、鍵に触れる。 | 位置だけでは解けず、実 camera の投影・視野・遮蔽を満たす必要がある。6° の一般対象取得を鍵の正解へ流用しない。 | 鍵のラッチが動き、入口への短い帰路が開く。 |

B の二枚は同じ opaque sRGB gray `#808080`、第三は `#B0B0B0` または `#505050`。不一致の見本 ID と第三の値を組み合わせた 6 種の事前設計 variant を持つ。初回の章開始と明示的な章リセットで 32-bit seed を一度選び、B/C 共通の seed と B の `seed % 6` variant を checkpoint に確定する。再開・描画再試行・同じ起動中の再入場では引き直さない。73 はテストと空保存の初期 fallback で、通常の新規プレイを固定する値ではない。B の保存済み seed/variant がその周回の配色を決める。正しいペアだけを比較台で同じ色へ書き換える処理はない。

C の目標角は各頂点から重心への `atan2`。通常の角度差は円周上で正規化し、初期許容値は 8°。これは製品上の判定値で、知覚を測定した数値ではない。ドラッグ中の表示角度と判定角度が一致した状態でのみ明示的解放を行う。円盤の中心 25% の範囲では角度追跡を中断し、外へ戻る最初のイベントで基準を置き直して急な反転を防ぐ。指を離した時だけ確定角を保存し、cancel・pause は最後の確定角へ戻す。

B の周囲比較と C の輪郭ガイドは、操作モードを切り替えても共有する 1,000 ms の待ち時間で連打を抑える。これは医学的な安全性の保証ではない。

ヒントはプレイヤーが任意で開く。B/C の成功でヒント段階を戻し、C の操作中は C のヒントを優先する。B/C の途中に D の視線補助を表示しない。A は色の手前奥から線の連続へ、B は見本の周囲から二枚の値へ、C は三つの切り欠きの向きへ、D は観察場所と投影の一致へ順に注意を向ける。補助だけを選んで自動解放にはしない。VoiceOver と明示したボタン操作では、同じ装置の意味付き操作を使う。音・色・速さを攻略条件にしない。

## 扉と帰路

| Gate | 開く条件 |
| --- | --- |
| A → 中央回廊 | 紋章 A を解放 |
| B の近道 | B を解放 |
| C の近道 | C を解放 |
| 中央回廊 → D | B と C の両方を解放 |
| D → 帰路 | 実投影による鍵 D を解放 |
| 最後の扉 | A/B/C/D と帰路 variant を満たし、扉への明示的操作 |
| 完了 | 最後の扉を通って外へ歩く |

描画と衝突は同じ world 定義の扉状態を参照する。帰路の変化は、変化する領域全体の遮蔽と安全な位置を確認してから `entrance` から `exit` へ切り替える。入口の目印は残り、カメラやプレイヤーを瞬間移動しない。左の高さ違いの双柱・右柱・欠けた上枠は `z=3.2..3.46` にあり、開始位置 `(0, 1.6, 7)` の正面で覚えられる。帰りの比較位置 `(0, 1.6, -0.2), yaw=π` からも同じ目印を見られ、変化領域 `z>=6` の手前に残す。これは設計された空間の変化で、医学的な変化盲の検査ではない。

## 保存とリセット

旧章は `chroma-rift.first-person.chapter.v1`、展示室は `chroma-rift.perception-gallery.v1` を使用する。章全体の一つの checkpoint が A/D と B/C の進行をまとめて保存し、別の writer で同じ封印を二重保存しない。

展示室の checkpoint は章 ID/version、各 seed、B variant/確定 slot、C 確定角、解放状態、試行数、B/C を選んだ順序、帰路 variant を持つ。pointer、操作モード、native player、途中の補間、経過時刻は保存しない。新規 seed の保存を試み終えてから native 描画画面へ進む。保存失敗時もその起動中の seed をメモリに保持し、再入場で引き直さない。保存は既存の直列 queue と session lease を共有し、古い画面の callback や reset 前の保存で進行を復活させない。

未知版・破損した展示室の記録は元の bytes を保持して保存を停止する。「保存を保持して展示室を試す」は保存しない試行であり、既存記録の正常な再開を意味しない。位置だけを安全な地点に復旧できる記録は `chroma-rift.perception-gallery.backup.v1` に一度だけ原文を保管してから新保存を行う。

設定では現在選択中の章名を付けた「この章だけを最初から」と、全データのリセットを分ける。章だけのリセットはもう一方の章・調整・操作・音の設定を残す。全データのリセットは両章、共有設定と調整を削除する。

## 音と検証の境界

「サウンド」をオフにしても全章を進める。環境音と効果音は独立したユーザー設定で、ゲームが音量を上げない。消音スイッチを尊重し、pause・背景移行・描画失敗・退出では音を止める。旧 Development Build に音の native module がなければ設定内で更新を案内し、音なしで継続する。

色彩立体視、同時対比による明暗の印象、Kanizsa 型の主観的輪郭、幾何学的投影は別の仕組み。データ・描画定義・ゲーム判定の検査を、人が錯覚を感じた証拠とは呼ばない。iPhone の見え方・操作・音の実聴・快適さ・性能は [実機手順](IPHONE_VALIDATION.md) で確認し、今回の実施範囲は [Goal 006](GOAL-006.md) に記録する。

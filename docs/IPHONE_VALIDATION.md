# Goal 002 — 同じDevelopment Buildで確認する

既存のDevelopment Buildの導入・起動は完了済みです。今回のJS/TS変更のためのクラウドビルド、認証、署名変更、EAS Updateは不要です。

## 再読み込み

WSLで次を実行します。

```sh
cd /home/mhirotaka/workspace/chroma-rift
node --version
npm --version
npm run start:dev-client
```

iPhoneでインストール済みCHROMA RIFTを開き、これまで使ったMetro接続を選んでReloadします。LANが通らない場合はMetroを止め、`npm run start:dev-client:tunnel` で起動し直します。

## チェックリスト

- [ ] 元の設定が復元される。保存済みの詳細プロフィールがあれば「遊ぶ」から調整を省略する。
- [ ] 初回は3問ちょうど。赤／青／同じ・分かりにくいを各1タップで回答し、強さの質問が出ない。形が毎問変わり、静止している。
- [ ] 「あとで調整して遊ぶ」で開始でき、再起動後も毎回調整を強制しない。
- [ ] 大きな文字・小さい画面でも主操作を押せる。セーフエリア、見切れ、文字折り返し、44pt以上の操作を確認する。
- [ ] 浮遊回廊で床・側面・階段・上下の橋が読める。白いキャラクターの足と向き、着地が見える。
- [ ] 床タップは隣接する一区間だけ移動する。選べない床、側面、余白、HUDで瞬間移動しない。
- [ ] 小部屋でかけらを取り、戻る。下の回廊を回って入口へ再合流できる。階段の上で2つ目を取り、出口へ進む。
- [ ] つながらない橋の最初の視点では渡れない。視点変更で端が一致し、中立色の接続表示が出て渡れる。橋の往復もできる。
- [ ] 移動中に視点変更できない。連打しても二重移動や二重取得がない。
- [ ] 両面で「色をほどく／色を戻す」を試す。床の位置、遮蔽、カメラ、接続、かけらは変わらない。
- [ ] クリア後も同じ構図で色比較できる。2面クリア後はかけら4つと発見した仕掛けが表示され、速度採点やランキングがない。
- [ ] 一時停止・設定・説明・やり直し・ホームへ戻るが働く。移動中にバックグラウンドへ移し、戻ると一時停止し、再開後も進める。
- [ ] 補助表示を明示的に選んだ後、調整をやり直しても勝手に変更されない。
- [ ] VoiceOverで現在地と現在選べる移動先が読め、移動に合わせて候補が更新される。色を識別せずに両面をクリアできる。
- [ ] 「動きを減らす」とiOSの設定で歩行の揺れが止まる。視点は固定姿勢へ切り替わり、常時粒子や点滅がない。
- [ ] 軽い振動のオン／オフが反映される。触覚は端末側設定で抑制される場合がある。
- [ ] 「設定 → 詳しく調整する」は12問を維持する。交差条件で赤か青の一方だけが上に重ならない。
- [ ] データリセットは確認後に動く。既存データを残したい端末ではリセットを実行せず、別の検証データで試す。
- [ ] 新しい端末権限やアカウントを要求しない。開発者ラボと旧レールは通常ホームの主ボタン群にない。

見え方や違和感は実際の観察として記録します。無理に凝視せず、違和感があれば中断します。録画だけから色彩立体視の強度を測定したとは扱いません。

今回自動確認できるのはロジック、画面遷移、投影データ、型、JS exportです。実機の描画順、操作感、VoiceOver、触覚、フレームレート、錯視の有無はこのチェックリストで別に確認してください。

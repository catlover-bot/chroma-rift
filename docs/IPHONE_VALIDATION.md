# Goal 003.2 — 次のiPhone確認

expo-gl入りのDevelopment Buildをそのまま使います。再ビルド・再インストール・保存リセットは不要です。

1. Metroを停止し、以下を実行します。

   ~~~sh
   cd /home/mhirotaka/workspace/chroma-rift
   npx expo start --dev-client --tunnel --clear
   ~~~

2. CHROMA RIFTを完全終了して開き直し、新しいQRへ接続します。
3. 「遊ぶ」から部屋を開きます。壁・床・入口・小さな光の**形**が見えるか、向きを変えると実際の景色が変わるかを確認します。文字や背景色だけの変化は成功としません。
4. 案内どおり光へ近づき、必要なら少し下を向き、「しるべを調べる」を押します。成功の案内と床の輪への次の目的が出ることを確認します。途中の保存がある場合は現在の目的を進め、初回確認のためにデータ全体をリセットしないでください。
5. 床の模様を「色をほどく／戻す」で比較。一時停止／再開、背景／復帰、ホームからの入場を3回確認します。標準操作なら同時歩行・見回しと指離し／取消、簡単操作なら一歩・旋回を確認します。

## 部屋が見えない場合

1. 準備中／失敗画面または一時停止から「描画の診断」→「診断をコピー」。
2. 「R3Fの箱・床・壁を確認」で3つの形が見えるか確認。
3. 箱も見えない場合だけ「描画の診断」→「箱が見えない：生のGLを確認」で橙色の三角形を確認。
4. それぞれの見え方と診断を記録し、「探索へ戻る（進行を維持）」へ戻ります。

診断はローカルコピーのみで送信されません。失敗時の再試行は明示操作で最大2回です。操作方式の理由は「操作と快適設定」に表示します。GLの警告は、実際の形の表示不良と分けて記録してください。

修正後の実機表示・知覚・触覚・FPSはまだ未確認です。根拠と限界は[GOAL-003-2.md](GOAL-003-2.md)に記録しています。

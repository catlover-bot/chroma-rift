# Goal 005 — iPhoneで紋章とドラッグを確認する

**全項目、実機では実施待ち。** expo-gl入りの既存Development Buildを使う。依存・native設定の変更はないため、Goal005のための再ビルド、アプリ削除、全データリセットは不要。

1. 起動中のMetroをCtrl+Cで止め、WSLで起動する。

   ~~~sh
   cd /home/mhirotaka/workspace/chroma-rift
   npx expo start --dev-client --tunnel --clear
   ~~~

   既存CHROMA RIFTを終了・再度開き、新しいMetroへ接続する。診断revisionはgoal-005-emblem-r1。探索へ戻り、壁・床・扉・紋章の実際の形が見えることを確認する。
2. 新しい第一室を試す場合だけ一時停止から「章を最初から」。既存の色設定・旧迷宮・スコアは消さない。通常のドラッグで歩き、自然な角度から紋章に気付けるか、説明や攻略なしで記録する。
3. model／iOS／普段の明るさ／True Tone／Night Shiftを手で記録する。明るさ最大やアクセシビリティの無効化を指示しない。
4. 左を短く・大きくドラッグして保持し、領域の外でも保持、離すと停止するか確認。右で見回し、左右を同時に使って片方ずつ離す。第三の指で一時停止し、再開後は新しく触るまで動かないことを確認する。
5. 紋章へ近づいて「紋章を調べる」。カメラを静止させたまま色／無彩色を任意に一往復し、「何が手前／奥／差なしに見えたか」を自由に記録する。期待する色は教えない。長い凝視や素早い繰返しを要求しない。
6. 攻略を見ずに連続する形を探し、世界内の印を押す。迷った手掛かりを記録する。誤答後も同じ答えか、印の小さい戻り、正解時のかんぬきと扉、実際の通過／衝突が一致するか確認する。
7. 未確定の見え方・輪郭ガイドでも解けるか確認。ガイドは使用中と表示され、自動解錠／減点はない。ガイド付きの見え方は補助なしの観察結果と別に記録する。
8. 鍵の投影合わせ→帰路→変わった入口→最後の扉を通過。途中でpause、background/foreground、home/再入場を各3回。残留入力・正解の変化・扉の再解錠・描画再初期化がないか記録する。
9. Reduce Motion、文字拡大でもドラッグの希望を保つ。44pt操作、safe area、文字折返しを確認。VoiceOverの移動・旋回、「近くの紋章と印」のカスタムアクション、輪郭説明、読み上げ終了時の操作復帰を確認する。
10. 不快感があれば中止して記録する。実際のカクつき／応答を書き、60fpsや医学的安全性を先に断定しない。

320×568、390×844、430×932相当のサイズ・safe area・文字拡大は自動配置テストと実機で別々に確認する。第一室60〜120秒／全章5〜8分は設計目標で時間制限ではない。

45〜90秒程度の記録は両指ドラッグ→片方の指を離す→紋章の観察・印の反応→pause/resumeを中心にする。全チェックを繰り返す長い録画は不要。URL、QR、account識別子は映さない。[手動記録用紙](EMBLEM_TEST_LOG.md)を使う。

## 形が表示されない時

準備中／失敗／一時停止から「描画の診断」→「診断をコピー」。R3Fの箱・床・壁を確認し、それも見えない場合だけ生のGLの橙色三角形へ進む。「探索へ戻る（進行を維持）」で戻る。手動再試行は最大2回。ログを隠したり、部屋の実表示をラベル表示で代用したりしない。

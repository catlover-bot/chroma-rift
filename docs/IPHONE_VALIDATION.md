# 一人称Development Buildで確認する

## Goal 003.1 — インストール済みビルドでクラッシュ修正を確認

expo-glを含むGoal 003のDevelopment Buildをインストール済みなら、今回のJS/TS・Metro修正のための再ビルドは不要です。Metroを停止して、次を実行します。

```sh
cd /home/mhirotaka/workspace/chroma-rift
npx expo start --dev-client --tunnel --clear
```

CHROMA RIFTを完全に終了して開き直し、新しいMetroのQRコードへ接続してください。モジュール解決を変えたためFast Refreshだけで確認せず、アプリ削除や保存データのリセットはしません。

- [ ] ホームから一人称の章を開ける。
- [ ] `position`／undefined-objectの致命的エラーが繰り返されない。
- [ ] 新しいプロセスの初回起動でduplicate-Three警告が出ない。
- [ ] 壁・床・鍵の輪郭と3片が表示され、鍵の整列と扉の移動が以前と同じ。
- [ ] 同時歩行／見回し、指離し／取消、色比較が正常。
- [ ] 一時停止、背景復帰、ホームへ戻って再入場が正常。
- [ ] 残る低レベル警告は表示不良と分けて記録する。失敗した場合は最初のエラーのJS stackとcomponent stackを確認する。

ローカルのR3F回帰テストとMetroバンドル検証は、実機GPU描画の代わりではありません。修正の根拠と警告の整理は[GOAL-003-1.md](GOAL-003-1.md)を参照してください。

## Goal 003を初めて導入する場合の旧手順

**expo-gl追加によりSkia版Development Buildは再ビルドが必要です。Reloadだけでは不足します。** 旧版では案内からホームへ戻れることも確認します。

### 初回導入時の操作

既存の認証・登録端末・Bundle ID・developmentプロファイルを使用。エージェントは認証・クラウドビルドを実行していません。

```sh
cd /home/mhirotaka/workspace/chroma-rift
npx eas-cli@latest build --platform ios --profile development
```

完成したビルドを登録済みiPhoneへインストールしてから:

```sh
npm run start:dev-client:tunnel
```

新しいCHROMA RIFTからMetroへ接続。LANなら `npm run start:dev-client` も可。Expo Goによる確認ではありません。

eas.jsonはdevelopmentClient/internal配布、versionは0.1.0。ios.buildNumber、autoIncrement、cli.appVersionSourceの明示設定はありません。このGoalで番号管理・署名・識別子を変更していません。

## 実機チェック

- [ ] 新ビルドの初回起動／GL初期化。失敗時のホーム復帰。
- [ ] 3問またはスキップから一人称へ。保存済みなら調整を省略。
- [ ] 左スティック＋右指の同時操作。斜め速度、上下を向いた水平移動。
- [ ] 指離し／領域外／通知／背景／メニューで入力停止。UI操作が視点へ漏れない。
- [ ] 壁の角、薄い扉、閉じた扉、場外を通り抜けない。接近時の壁抜け表示。
- [ ] 対象名と操作IDが一致。背後・遠方・壁越しは操作不可。
- [ ] しるべ→輪→奥の装置で封印A。順序が違っても復帰。
- [ ] 鍵の片が入口では分離し、観察の輪から整列。「重ねる」で封印B。
- [ ] 位置／視線の判定境界、異なる縦画面で見た目と条件が一致。
- [ ] ヒント3段階、視点補助。補助が移動や解答確定を代行しない。
- [ ] 全3扉の描画と通行条件が開く進行に一致。
- [ ] 小部屋から戻れる。帰路逆走でも進行が壊れない。
- [ ] 同じ柱・額縁の先が広い出口の間になる。変更の瞬間が見えず強制旋回なし。
- [ ] 最後の扉を調べて歩くと結果。二重解除・クリアなし。
- [ ] 色比較が模様だけを変え、姿勢・形・扉・照明・進行は同じ。3DラボとSkia共有パレットも確認。
- [ ] 一時停止・背景復帰後は手動再開。再起動で安全位置と進行を復元。
- [ ] 簡単操作、感度、左右配置、低品質、補助、減動、触覚が動作・保存。
- [ ] safe area／文字拡大／小画面で主要操作が見切れず44pt以上。VoiceOverで対象・向き・状態を読める。
- [ ] 設定から詳細12問。既存回答・プロフィール・スコアが残る。旧2.5D回帰も可能。
- [ ] 章リセットは設定を保持。全削除は検証用データで試し、古い保存が復活しない。
- [ ] 退出／再入場／リプレイ10回でGPU資源が増え続けない。開発診断のdraw calls・frame timeを記録。
- [ ] 発熱、電池、フレーム時間、入力遅延。60fps達成を前提にしない。
- [ ] 色の奥行き、酔い、目の不快感を実際の観察として記録。違和感時は中断し無理に凝視しない。

テスト・JS export・ブラウザープレビューは実機検証の代替ではありません。VoiceOver同等性、触覚、快適性、色の見え方は実機未確認です。

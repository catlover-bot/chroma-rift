# Goal 006 — iPhoneで不確かな展示室を確認する

以下は**実機では実施待ち**。新章はホームの「新しい展示室を始める」から入る。既存の「旧章の続きから」を消さずに残している。Goal005と違いexpo-audioを追加したため、音を含む確認にはユーザーが新しいDevelopment Buildを作成・インストールする必要がある。アプリ削除・全データresetは必須にしない。旧Buildは音なしで継続する設計だが、新native機能はReloadだけでは増えない。

新Buildをインストールした後、WSLでMetroを起動する。

```sh
cd /home/mhirotaka/workspace/chroma-rift
npx expo start --dev-client --tunnel --clear
```

既存Metroが起動中ならその端末でCtrl+C後に実行する。診断revisionは `goal-006-gallery-r1`。準備中の文言だけでなく、壁・床・装置の実形状が表示されることを確認する。

## 短い通し手順

1. model/iOS/Build版/普段の明るさ/True Tone/Night Shift/文字サイズ/消音設定を手で記録。初回3問はスキップ可能。設定に音module更新案内が出る旧Buildと、新Buildを区別する。
2. 入口の片側二本柱と欠けた上桁を確認。左で連続歩行、右で見回し、両指→片方だけ離す、領域外までdrag、third finger pauseを試す。pause後は新しく触るまで動かない。左手設定でも役割が整合する。
3. Aの床の輪へ歩き、紋章全体と三つの印が一緒に見える位置で調べる。通常表示の見え方を自由に記録し、任意に色をほどく。期待する前後色を教えず、長い凝視を求めない。輪郭が連続する印を押し、印→かんぬき→扉と衝突が一致するか確認。
4. 中央回廊からB/Cを好きな順に選ぶ。片方だけ解いた時はD扉がまだ閉じている。各翼からの近道が開き、解き直しが不要なことを確認。
5. Bの輪から装置全体を見て「動かす」。三つの見本を直接drag、途中で持ち直し、二枚を左右socketへ配置。「周囲を外す」前後で見本の中心色が変わらず、比較だけで解放されない。誤った組合せ、外drop/cancel後も見本を失わず、同じ灰色の別々の二枚を置いて「つなぐ」で開く。
6. Cで各円盤の縁をなぞって回す。中心横断、持ち直し、-π/π付近で跳ばない。通常表示の中央に線や塗りがなく、任意の「輪郭ガイド」は破線と使用中表示になる。各切欠きを内側へ向けて「封印に触れる」と引き出し/近道が開く。知覚とゲームの成功を別々に記録する。
7. B/C操作中は歩行・見回しが混ざらず、戻る/pauseが常に届く。背景復帰時や指を離さず操作モードを抜けた時に入力が再生されない。別指がHUDを押しても装置を誤操作しない。
8. Dへ入り床の輪から位置と視線を調整。離れた断片と外枠ノッチを見て重ね、鍵に明示操作。ラッチと帰路の扉が開く。色や立ち位置だけで解放されない。
9. 短い帰路から入口へ。覚えた非対称の枠は同じで、その先が変わる。見ている空間の差替えやteleportがない。最後の扉を自分で開き、歩いて外へ出て完了画面へ進む。
10. 途中保存・ホーム・続きからを試す。B配置/C確定角/解放順が維持され、drag途中値は戻る。新章をresetしても旧章の進行は残る。旧章の続きからも旧条件でクリア可能。
11. mute、Reduce Motion、320〜430pt相当幅、fontScale1〜2、safe area、左手、簡単操作、VoiceOverで進める。Bは同じ見本の代替観察→自分で配置、Cはadjustable action→独立commit。文字拡大だけでdragを強制解除しない。
12. 足音が実移動だけで鳴り、壁へ押し付けるだけでは鳴らない。操作音/解錠/環境音、master/環境/効果の音量、silent switchを確認。pause/background/描画失敗/退出で止まり、再開時に過去の音をまとめて鳴らさない。

初回は再入場・背景復帰を3回、継続性能確認では10回行う。renderer/context/texture/audio playerが増え続けないかを実測し、通常の開発実行・録画あり・本番相当を分けて記録する。60fps、実機の音量/発熱、錯視の強さ、8〜12分の初見目標は自動テスト結果から推定しない。

不快感があればpause・退出し、その状況を記録する。強い明るさ、ヘッドフォン、片目を隠すこと、特殊な目の状態は要求しない。短い録画を使う場合は指の操作説明を添え、URL/QR/account識別子を映さない。アプリ内pauseと開発ランチャーのアイコンを区別する。

## 表示できない場合

準備中/失敗/一時停止から「描画の診断」→「診断をコピー」。R3Fの箱・床・壁、それも見えない時だけ生のGLの橙色三角形を確認する。「探索へ戻る（進行を維持）」で戻る。手動再試行は最大2回。取得した診断と実際の画面を分けて記録する。

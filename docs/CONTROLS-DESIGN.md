# Goal 005 — 探索操作の設計（Goal004操作を維持）

普通の開始設定はドラッグ操作（保存値 `standard`）。左の広い領域で歩き、右の領域で見回し、中央の照準で選んだ対象を右下のボタンから調べる。左右配置は入れ替えられる。ボタン操作（`simple`）は最初の一時停止メニューで選べる。

## 入力と配置

| 項目 | 現在の値・規則 |
| --- | --- |
| 移動リング | 116 logical points、最大変位50 points。表示位置だけ端に収め、入力原点は指を置いた位置を保つ |
| 移動の応答 | 半径方向のdead zone 0.14、その外側は単調な線形応答。斜めを単位円に収め、既存の歩行速度を上限にする |
| 歩行 | 指を置くだけではゼロ。変位を保てばフレームごとに経過時間で移動。衝突は既存worldで検査 |
| 視点 | 自分のpointerの前回からのpageX/Y差分。1 pointあたり0.003 radians × 感度。上下は追加倍率。通常の指離しに含まれる最終差分も一度だけ消費し、次frameに再生しない |
| 停止 | 指離しは所有pointerを解放（歩行は即停止、lookの最終要求差分は一度だけ適用）。取消はその所有と未消費差分を破棄。中断・メニュー・失敗・配置/操作変更・終了では所有と未消費差分を破棄 |
| レイアウト | SafeArea内で左右のドラッグ領域、上の一時停止/目的、下の操作列を分離。操作対象は44 points以上、主操作は64 points以上を基準 |

`touchAdapter.ts` はインストール済みReact Native 0.86のnative touch emitterに合わせたJS側adapter。iOSの元のemitterがtouchの存続中保持され、Fabricの `changedTouches` が複数領域を含みうることをソースで確認した。開始時は `targetTouches` 所属を照合し、移動・終了時は取得済みpointer IDを照合する。終了時に `targetTouches` が空でも所有pointerを解放する。表示リングの端や画面の中点をまたいでも所有を変えない。

子Textやノブに対する `locationX/Y` は使わず、安定した `pageX/Y` を使う。メニューや操作ボタンはドラッグ領域と別のhit view。scene上のSceneActionButtonは独立したnative touch ownerを持つ。RN Pressabilityがglobal touchesの先頭を使って別の親指を追い、第三の指のtapを取り消すことを防ぐ。ボタン自身で始まったpointerだけを採用し、14 pointsを超える移動やcancelでtapを取り消す。sceneからドラッグしてボタン上で離しても操作しない。VoiceOverのactivateは意味付き操作として保持する。装飾は `pointerEvents="none"`、HUDの親は `box-none`。adapterのgenerationが破棄済みcallbackを拒否する。Reanimatedはリング/ノブの表示値だけを扱い、ThreeやJS controllerをworkletから変更しない。カメラ・位置・リングに毎フレームReact stateを使わない。

## 見つける・調べる

`interaction.ts` の同じ評価をHUDと操作確定時に使う。紋章の三つの印・通常の扉は中心6°の小さな取得範囲を持つ。正確なray hitを優先し、それ以外は角度・距離・安定したID順で選ぶ。対象の中心とrayについて不透明worldの遮蔽、距離、前方を検査する。大きな紋章板は別に実ray-plane交点を使い、矩形の可視端でも距離と遮蔽を検査する。遠方の案内には実カメラの投影と姿勢の一致も必要。

対象なしでは静かな照準だけ。見えるが遠い場合は名前と接近の案内。届く場合は対象名を含む操作、条件不足なら理由を示す。操作ボタンを押すたびに現在の状態で再評価し、照準を横切るだけでは操作しない。

重なる鍵はこの6°拡大の対象外。実カメラ行列による投影整列、観察位置、遮蔽、第一の封印を必要とする。色比較・操作方式の切り替えは謎を進めない。頭の揺れ、roll、カメラ慣性、強制旋回、FOV変化は追加しない。

## 文字・読み上げ・導入

Reduce Motionは装飾の動きを減らし、文字拡大は折り返しや配置を変える。どちらも `standard` を `simple` にしない。VoiceOver中は意味のある移動/旋回/調べるボタンを表示し、保存したタッチ操作は保持する。読み上げ終了時に保存した表示へ戻る。

旧 `simple` 保存に意図の記録はないため、その選択を保持する。一時停止で「ドラッグ操作を試す」「今の操作を使う」を一度だけ案内する。別文書 `chroma-rift.first-person.onboarding.v1` に版・操作案内確認・導入完了だけを保存する。既存のcalibration、controls、chapter文書で代用しない。

歩行の案内は衝突後の実変位0.65 world units、見回しの案内は実操作による合計0.24 radiansで達成する。順番は固定せず記録し、両方の実操作で導入を終える。紋章の観察は移動／見回しの実績を代用しない。メニュー・色比較・描画callback・明示的な視点補助では達成しない。しるべを調べた既存の章や完了済み導入を再要求しない。

数値は初期の製品調整値。実機の感度、指の届きやすさ、文字の見やすさは[実機確認](IPHONE_VALIDATION.md)で調整する。参考資料と検証結果は[Goal005記録](GOAL-005.md)と[Goal004の参考資料](GOAL-004.md)にまとめる。

`actor-front/quarter/side/back` は改修前と同じcamera識別子。quarterは約81度の斜め視点で45度ではない。旧頭部意匠は+Z、新モデル前面はdomainと同じ-Z。

`actor-*-shelf-entry` は棚の端と入路を見せる視点、`actor-*-shelf-hidden` は棚に実mesh全頂点が遮られる位置。`actor-searching` は棚の端から覗く別の位置で、全身不可視の証拠ではない。追跡の中断自体は実controllerの検証で扱う。

`notebook-*` はクリア後の自由比較fixture。未発見を発見済みへ変更していない。画像にある「音の錯覚」は表示確認だけで、実聴を行っていない。
